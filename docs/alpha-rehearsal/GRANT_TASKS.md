# Review the supporting grant

Work through one pack in the dashboard and the other with your usual record-review tools. The facilitator assigns the pack and order. Keep the key separate. Each case records a fictional account review.

**Dashboard.** Open the local dashboard and choose **Regression inbox → Import review package or case**. Import the first assigned `dashboard/case-01.json`. Open **Actions and supporting grants** and choose a candidate action. Use **Parent grant** and **Return to this action** to inspect its authority. Repeat with the other two cases. For one case, reload while looking at a parent and record which run, action and grant reopen.

**Ordinary review.** Use the other pack’s `records/baseline.json` and three candidate records. Review them with the tools you normally use. The `dashboard/` files include a report and belong to the other review method.

For each candidate, record the run ID, what the research and final actors did and for whom. Is the action covered throughout the delegation chain? Cite the action, resource, time, the relevant grant or missing ID and parent authority. When the same ID appears in two runs, compare what each record actually supplies.
