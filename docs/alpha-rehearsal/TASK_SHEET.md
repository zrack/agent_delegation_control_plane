# Private alpha reviewer task sheet

Use the supplied fictional files and a fresh browser profile. From the repository
checkout, run `python3 scripts/serve.py` and open the local dashboard address
printed by the command. If the port is in use, start the server with `--port 48735`
and use the address it prints. Start a timer before setup. Record any step you
could only finish with help.

## Review the three cases

1. Open **Regression inbox** and use **Import review package** to open each of
   `case-01.json`, `case-02.json`, and `case-03.json` from this folder.
2. For each case, record the current evidence check and explain it in your own
   words. Identify who acted for whom, the recorded action and resource, and the
   grant or evidence that supports your explanation. Open the relevant details.
   If a matching grant is absent from the differences, use the action's grant ID
   to find it in the package JSON.
3. For each flagged case, save a **Decision** and a **Reason for decision**.
   Record what you would ask the workflow owner to do next.

## Review the follow-ups

1. Return to the item imported from `case-02.json`. Under **Attach follow-up
   package**, select `follow-up-01.json` and record the result and the state of
   **Close as resolved**. Then select `follow-up-02.json` and do the same.
2. Return to the item imported from `case-03.json` and attach `follow-up-03.json`.
   Record the original and follow-up verdicts for each accepted attachment.
   Inspect the follow-up actions and grants before deciding whether to close.
3. Reload the dashboard. Confirm what happened to your decisions and case states.

## Return your observations

- Setup time and total elapsed time.
- Which steps needed help and what help was needed.
