# Roadmap

## Next evidence gates

1. Complete same-repository privacy preparation, including GitHub-hosted history surfaces, before any public visibility change.
2. Run a guided technical alpha with a small group of engineers using fictional or separately permissioned records. Measure setup friction, correct explanations and assistance needed.
3. Select one frozen, permissioned operational workflow and compare the dashboard with the investigator's existing method. Record accuracy, elapsed time, missed issues and unchanged/worse results.
4. Choose the next source adapter or evidence capability from observed needs. General live ingestion, authenticated identities, revocation and action enforcement require separate architecture and proof.

Source publication does not establish production readiness or operator value. Deployment and real-data use remain separate decisions.
