# Contributor instructions

Read README.md, ARCHITECTURE.md, RIGHTS.md and SECURITY.md. Use fictional inputs,
preserve the loopback-only viewer boundary and run `python3 scripts/check.py`.
Run the optional offline SDK checks when changing the integration. Source is
canonical; rendered diagrams must match their Mermaid sources. Do not include
keys, personal records, private logs or machine paths in commits. Publication,
external contact, credentials, model spending and deployment require maintainer
authorization. Tests do not establish identity authentication or production readiness.
